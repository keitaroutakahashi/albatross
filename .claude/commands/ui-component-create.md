## やること

- 引数で指定したコンポーネント名で UI コンポーネントを作成する
- コンポーネントは `src/app/_components/$ARGUMENTS/index.tsx` として作成する
- コンポーネント作成後 `src/app/_components/$ARGUMENTS/index.test.tsx` としてテストファイルも作成する
- `pnpm lint && pnpm typecheck`を実行し、エラーがないことを確認する

## 参照するファイル

- 既存の実装を参考にすること @src/app/\_components/\*\*
